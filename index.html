DocGen

Generate documents from templates — entirely in your browser.

Use {{variable}} syntax in your templates. Filters: {{value|fmt_date}}, {{value|fmt_dec}}, {{value|fmt_month}}, {{value|fmt_iban}}. Word templates generate one document per row. Excel templates (header row + template row) produce a single file with all rows expanded.

Excel file with one row per document. Column names are normalized to snake_case.
